Probability Rules Explained

Union Rule

P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

Intersection Rule

For independent: P(A ∩ B) = P(A) × P(B)
For mutually exclusive: P(A ∩ B) = 0

Conditional Probability

P(A|B) = P(A ∩ B) / P(B), if P(B) ≠ 0

Contradictions

Events cannot be both independent and mutually exclusive. Intersection can't exceed individual probabilities.
