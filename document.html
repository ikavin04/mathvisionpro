Introduction

MathVision Pro is an advanced statistics calculator suite designed for students, educators, and professionals. It provides a comprehensive set of tools for statistical analysis, probability calculations, and data visualization.

This documentation covers the API reference, usage examples, and advanced customization options for developers looking to integrate MathVision Pro into their applications or extend its functionality.

Key Features

  • Comprehensive statistical functions
  • Interactive visualizations
  • Modular architecture
  • Extensible API

Components

  • Core calculation engine
  • UI components library
  • Data visualization module
  • API interface layer

Installation

MathVision Pro can be installed via npm for integration into your JavaScript projects, or included directly via CDN for quick prototyping.

npm Installation

npm install mathvision-pro

CDN Usage

<script src="https://cdn.jsdelivr.net/npm/mathvision-pro@latest/dist/mathvision.min.js"></script>

Dependencies

MathVision Pro has the following peer dependencies:

  • chart.js (^3.7.0) - for visualizations
  • math.js (^10.0.0) - for advanced calculations

Note

For Node.js usage, you'll need to import the ES module version: import { Stats } from 'mathvision-pro';

Quick Start

Get started with MathVision Pro in just a few lines of code. This example shows how to calculate basic descriptive statistics for a dataset.

Basic Usage

// Initialize the Stats module
const stats = new MathVision.Stats();

// Sample dataset
const data = [12, 15, 18, 22, 17, 14, 19, 21, 16, 20];

// Calculate descriptive statistics
const results = stats.descriptive(data);

// Output the results
console.log(results);
/* Output:
{
  mean: 17.4,
  median: 17.5,
  mode: [],
  range: 10,
  variance: 9.44,
  stdDev: 3.07,
  quartiles: { q1: 15, q2: 17.5, q3: 20 }
}
*/

Visualization Example

// Create a histogram visualization
const viz = new MathVision.Visualization();

viz.createHistogram({
  element: '#chart-container',
  data: data,
  bins: 5,
  colors: {
    bar: 'rgba(143, 0, 255, 0.7)',
    border: 'rgba(225, 0, 255, 1)'
  },
  title: 'Data Distribution'
});

Tip

Check the browser's console for detailed output when debugging calculations. All methods provide verbose logging in development mode.

Descriptive Statistics API

The Descriptive Statistics module provides methods for analyzing and summarizing datasets.

method

descriptive(data, options)

Calculates all descriptive statistics for a dataset.

Parameters

  • data (Array) - The dataset to analyze
  • options (Object) - Optional settings:
    • precision: Number of decimal places (default: 2)
    • include: Array of stats to include (default: all)

Returns

Object containing all descriptive statistics.

Example

const results = stats.descriptive([10, 20, 30, 40], {
  precision: 3,
  include: ['mean', 'stdDev']
});

// Output: { mean: 25.000, stdDev: 12.909 }
method

calculateMean(data)

Calculates the arithmetic mean of a dataset.

Parameters

  • data (Array) - The dataset to analyze

Returns

Number representing the mean.

Example

const avg = stats.calculateMean([5, 10, 15]);
// Output: 10
